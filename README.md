# Jump Tracker (React)

Переписанная версия приложения для тренировок вертикального прыжка.
Тот же Supabase и те же данные, что у старой версии (`jump-tracker/index.html`) —
оба приложения можно использовать параллельно, аккаунты общие.

## Структура

```
src/
  data/program.ts        — 23 дня базовой программы, видео, показатели замеров
  lib/                   — конфиг Supabase, localStorage, утилиты (1ПМ, даты)
  store/AppStore.tsx     — всё состояние + синхронизация кэш ↔ облако
  components/            — общие: шторка (Sheet), таймер отдыха
  features/
    auth/                — вход и регистрация
    program/             — программа, день, редактор упражнения, шаблоны
    workout/             — активная тренировка
    metrics/             — замеры
    stats/               — графики и журнал
    students/            — кабинет тренера
    settings/            — 1ПМ, свои показатели, бэкап, сброс
```

Ключи Supabase — в `src/lib/config.ts`.

## Запуск локально

1. Установи Node.js 22.12 или новее с [nodejs.org](https://nodejs.org) (галочки по умолчанию).
2. В папке проекта:
   ```
   npm install     # один раз
   npm run dev     # запуск — откроется http://localhost:5173
   ```
3. Правки в коде видны в браузере мгновенно, без перезагрузки.

## Сборка и деплой на GitHub Pages

Вариант А — автоматически (рекомендую):
1. Создай новый репозиторий `jump-tracker-react` на GitHub (public).
2. Залей туда всё содержимое этой папки (включая `.github/workflows/deploy.yml`).
3. В настройках репозитория: Settings → Pages → Source: **GitHub Actions**.
4. После каждого пуша в `main` сайт соберётся и опубликуется сам:
   `https://icheve.github.io/jump-tracker-react/`

Вариант Б — вручную:
```
npm run build
```
Содержимое папки `dist/` залить в любой хостинг статики.

Сборка включает Web App Manifest и service worker. После первого успешного открытия
приложение и уже загруженные статические ресурсы доступны без сети. Изменения данных,
сделанные офлайн, сохраняются локально и автоматически отправляются в Supabase при восстановлении связи
(либо при следующем запуске приложения).

## Обновление существующей Supabase-базы

Для базы, созданной старой версией `supabase-setup.sql`, выполни один раз в SQL Editor:

```
../jump-tracker/migrations/20260721_harden_profile_roles.sql
```

Миграция запрещает тренерам назначать и снимать служебные роли `trainer`/`admin`.
